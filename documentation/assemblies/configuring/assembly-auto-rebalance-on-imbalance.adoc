= Auto-rebalancing clusters to fix imbalances

[role="_abstract"]
Enable automatic rebalancing of Kafka clusters when Cruise Control detects goal violations and cluster imbalances.
This feature leverages Cruise Control's anomaly detection capabilities to identify problems like uneven partition distribution, overloaded brokers, and resource constraints, then automatically triggers rebalancing operations to restore cluster balance.
Unlike manual rebalancing or the Cruise Control self-healing mechanism, Strimzi's auto-rebalance on imbalance keeps the Cluster Operator in full control of all rebalancing operations while respecting maintenance time windows and cluster stability.

IMPORTANT: This feature is currently in *early access* and subject to change.
Do not use in production clusters. Feedback and testing on non-production clusters are encouraged to help shape the final design.
