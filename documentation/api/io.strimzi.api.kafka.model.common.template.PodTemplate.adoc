Configures the template for non-stateful pods.

.Example `PodTemplate` configuration
[source,yaml,subs=attributes+]
----
# ...
template:
  pod:
    metadata:
      labels:
        label1: value1
      annotations:
        anno1: value1
    imagePullSecrets:
      - name: my-docker-credentials
    securityContext:
      runAsUser: 1000001
      fsGroup: 0
    terminationGracePeriodSeconds: 120
    nodeSelector:
      example.com/workload: kafka
    hostAliases:
      - ip: "192.168.1.86"
        hostnames:
        - "my-host-1"
        - "my-host-2"
    #...
----

Use the `hostAliases` property to a specify a list of hosts and IP addresses,
which are injected into the `/etc/hosts` file of the pod.
This configuration is especially useful for Kafka Connect or MirrorMaker when a connection outside of the cluster is also requested by users.

Use `nodeSelector` to restrict the pod to nodes with all the specified labels.
If you also configure required node affinity, both the selector and the affinity rules must be satisfied.
